The goal is to simplify compliance assessments, organize cybersecurity controls, and make it easier to track evidence, risks, and corrective actions.

Key Features:
- Interactive dashboards to visualize compliance indicators.
- Compliance tracking across NCA cybersecurity frameworks.
- Evidence management and control mapping.
- Risk management and corrective action tracking.
- Automated reports and indicators that update based on entered data.
- Easy navigation with an organized index and internal links.

Throughout the development process, I've focused on simplicity, usability, and turning  compliance data into clear, actionable insights.

This project is still under continuous development and improvement.
I'm working on adding new features, enhancing the user experience, and making the tool more comprehensive and effective.

-This is an independent personal project and is not an official NCA tool.
